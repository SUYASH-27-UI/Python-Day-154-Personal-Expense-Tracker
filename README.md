# Python Day 154 - Personal Expense Tracker

## Description
A Python application to record and analyze personal daily expenses using CSV file storage.

## Features
- Add daily expenses
- View all expense records
- Calculate total spending
- Generate category-wise expense summaries
- Search expenses by category
- Automatically save expense records

## Files
- `expense_tracker.py` - Main Python program
- `expenses.csv` - Expense records

## Requirements
- Python 3.x

## How to Run
Keep both files in the same folder.

```bash
python expense_tracker.py
```

## Concepts Used
- CSV module
- Dictionaries and lists
- Date handling
- File handling
- Functions
- Exception handling
